Prompt 8:

Build the LangGraph workflow in src/graph.py.
 
State (AgentState, TypedDict): messages (add_messages), query, sub_queries, selected_agent,
candidate_agents, route_reason, route_mode, retrieved_context (list, operator.add), sources,
draft_answer, human_feedback, revision_count, review_log (list, operator.add). MAX_REVISIONS = 2.
 
build_graph(route_fn, rewrite_fn, answer_fn, retrievers, checkpointer=None) with these nodes:
- supervisor: calls route_fn, stores candidates, selected agent, reason and route_mode
  ("multi" when more than one department, otherwise "single").
- conditional edge after supervisor: one department -> go straight to that agent node;
  two or more -> go to route_review.
- route_review (HUMAN checkpoint 1, multi-department only): interrupt() with the question, the detected
  agents, the reason, allowed actions approve/reject and the numbered agent options.
  approve -> goto split_query. reject -> the human sends agent_number 1-4; set selected_agent and
  goto rewrite_query. Log both to review_log.
- split_query: one sub-question per detected department using rewrite_fn; then a conditional edge that
  returns the LIST of those agent names so LangGraph runs them in parallel.
- rewrite_query: rewrite the question for the single chosen agent; then go to that agent.
- one node per agent: retrieve with its own sub-query (or the main query), format the context with its
  source labels, and append one entry to retrieved_context.
- answer: join every agent's context, call answer_fn, and append a "Sources" list of the unique labels
  to the draft.
- answer_review (HUMAN checkpoint 2, always): interrupt() with the draft, the agents used and the
  revision count. approve -> final answer; edit -> use edited_answer; revise -> store feedback,
  revision_count + 1 and go back to answer, but release the latest draft once MAX_REVISIONS is reached;
  reject -> a message saying the reviewer did not approve. Log every decision.
Compile with InMemorySaver so each run has its own thread_id.
 
Also write run_question(graph, question, reviewer, scope_fn=None, thread_id=None): rejects an empty
question, stops with the out-of-scope message when scope_fn says no, invokes the graph, and keeps
resuming with Command(resume=reviewer(payload)) while "__interrupt__" is in the result. It returns
status, final_answer, agents used, sources and review_log.
 
src/reviewers.py:
- console_reviewer(payload): a real person types the decision. Route review: approve (a) / reject (r),
  then press 1-4. Answer review: approve (a) / edit (e) / revise (v) / reject (r), asking for the text
  or the feedback. Invalid or empty input is refused and asked again.
- scripted_reviewer(*decisions): returns the given decisions in order, then approves. For tests and for
  your own runs, because you cannot type into input().
